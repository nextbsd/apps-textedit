# TextEdit

TextEdit is fork that improves and make it work well as part of GNUstep Desktop.

#### Notable changes:

- links panel
- better support for attachments
- scripting with StepTalk


#### Icons

The document icons (`text.tiff`, `rtf.tiff`, `rtfd.tiff`) are from Rik icons
by Bertrand Dekoninck (https://github.com/gnustep/icons-rik), licensed under
the Creative Commons Attribution 4.0 International License
(https://creativecommons.org/licenses/by/4.0/). They are Rik's genericText and
rtf file icons scaled to 96 by 96 pixels; `rtfd.tiff` is Rik's rtf icon with
the label changed to RTFD.
